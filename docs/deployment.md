# Déploiement — HappyBite

## Démo en ligne (ESPRIT / jury)

| | |
|--|--|
| **URL** | https://happybite-demo.infinityfreeapp.com/ |
| **Hébergeur** | [InfinityFree](https://www.infinityfree.com/) |
| **Mot de passe démo** | `password` (tous les comptes fictifs) |

Aucune installation requise pour tester l’interface : ouvrir l’URL, se connecter via le menu **Profil**.

### Comptes recommandés

| Rôle | E-mail |
|------|--------|
| Admin | `admin@happybite.tn` |
| Fournisseur | `fournisseur@happybite.tn` |
| Nutritionniste | `nutritionniste@happybite.tn` |
| Client | comptes fictifs en base (ex. `sarra.benali@gmail.com`) |

### Limites hébergement gratuit

- **IA** (OpenAI / Gemini) : nécessite `config/secrets.php` sur le serveur
- **E-mail** (changement mot de passe) : nécessite `config/mail.php` (SMTP Gmail)
- **Face ID** : peut être limité selon le navigateur et HTTPS
